# Official Uzbekistan Export Statistics

These files were downloaded from the National Statistics Committee of Uzbekistan's SIAT database on 18 November 2026.

| File | Coverage | Unit |
|---|---|---|
| `exports_by_commodity_annual.csv` | Annual, 2010–2025 | Thousand US dollars |
| `exports_by_commodity_monthly.csv` | Monthly series published by SIAT (see column headings) | Thousand US dollars |

The tables cover exports across commodity categories classified under Uzbekistan's TN VED; they are not limited to agricultural products. Filter the commodity descriptions for the agricultural and food categories relevant to your research. The original SIAT CSVs are preserved as downloaded.

## Official SIAT sources

- [Annual export value by 2-digit TN VED category](https://siat.stat.uz/data/3078/?lang=en)
- [Monthly export value by 2-digit TN VED category](https://siat.stat.uz/data/3080/?lang=en)

SIAT lists the unit as thousand US dollars and the license as CC BY 4.0. Use the source pages for definitions, metadata, and the latest available files.
